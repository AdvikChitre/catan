# 13. Locked Design Decisions

This file records the choices made during design so an implementation agent does not reopen them.

1. Exactly four players in version 1.
2. Standard Catan rules only; no expansions.
3. Ports included.
4. Robber fully implemented.
5. All standard development cards included.
6. Simulator instantiates and owns the four bot instances.
7. Simulator calls bot methods; bots do not directly call simulator mutations.
8. Bots may hold arbitrary private memory for the duration of a game.
9. Bots receive player-specific read-only GameView snapshots.
10. GameView contains current observable state only; no event history.
11. Bots receive observable events in real time through OnEvent and may remember or ignore them.
12. Opponent resource counts and development-card hands are hidden.
13. Resource receipt from dice is observable and is published as an event.
14. Trade offers, responses and counter-offers are observable table events.
15. Player-to-player trades are transactions; at most one final trade completes from a negotiation.
16. AvailableActions are generated by the simulator.
17. Build locations are enumerated as concrete actions.
18. Trade is represented as an umbrella action and the bot supplies the concrete offer afterward.
19. Complex actions such as robber choice and Year of Plenty use follow-up decision requests.
20. There is no artificial two-action trade/build iteration limit. Continue until EndTurn.
21. Longest Road and Largest Army are simulator-calculated.
22. Victory points are simulator-calculated.
23. Three seconds is the maximum gameplay decision time.
24. Same seed + same bots must yield the same game.
25. Simulator is independent of the web UI.
26. Web client consumes public state/events/replay produced by simulator.
27. Board is a graph of 54 vertices, 72 edges and 19 tiles.
28. Vertex coordinates use the supplied x/y coordinate system.
29. BoardGeometry is immutable topology; BoardState is mutable gameplay state.
30. Bots never receive raw Simulator, GameState, BoardState or Bank references.
